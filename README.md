# ねこパンチ・モール（three.js）

物をぜんぶ壊すゲーム。黒ねこ（`assets/images/cat.aseprite`）のねこパンチで、小物から壊していきます。壊すほど XP がたまってレベルが上がり、ねこが指数的に大きくなって（全 12 レベル。1 レベルで約 2.4 倍、Lv.1 の 0.64m → Lv.8 で約 290m → Lv.12 で約 10km）、世界も広がります。

ペットショップ奥の ねこ部屋 → ショッピングモール → 住宅街 → マンション街 → オフィス街 → 超高層ビル街 → 山と海（富士山）→ Lv.10 で地球を飛び出して宇宙へ（人工衛星・小惑星 → 月・惑星 → 木星・土星・太陽）。最後に巨大な惑星と太陽をぜんぶ壊すと、太陽系が崩れてクリアです。

**遊ぶ**：GitHub Pages で公開しています（ビルド不要の静的サイト。PC のキーボードで遊べます）。

**手元で動かす**：このフォルダで `python3 serve.py` を実行して `http://localhost:8765/` を開きます（キャッシュしない開発用サーバー）。

操作：WASD / 矢印で移動、Shift で走る、Space でジャンプ（高い棚に届く）、J / F でねこパンチ、ドラッグでカメラを回す、ホイールでズーム、M で音の ON / OFF、G で図鑑、P で画質（高 / 標準 / 低）

| URL オプション | 内容 |
|---|---|
| `?debug` | コンソールから `game` を触れる（例: `game.setLevel(9)`） |
| `?lv=N` | レベル N から始める |
| `?debug` で `game.zukan.unlockAll()` | 図鑑をぜんぶ見つけたことにする（確認用。次に物を壊すと保存されるので注意） |
| `?gallery` | 物の見本帳。← → で切り替え、ドラッグで回転、ホイールでズーム（`?gallery=bench` でその物から）。コンソールで `gallery.sheet(0, 48)` を呼ぶと一覧表を出す |

## しくみ

- 段階（tier）1〜12。1 レベル = 1 段階で、tier t は Lv.t で壊せる（`src/config.js` の `TIERS`）。大きさの目安は「その時のねこの半分くらい」。それより大きい物を叩くと「かたい！」とはじかれる
- 2 段階以上小さい物（Lv.2 からは小物も）は、歩いてぶつかるだけでつぶれる。ねこよりずっと小さい物は描画を省く
- レベルアップに必要な XP は、置いた物の合計から自動で決まる（`GROW.share`：その段階の物の 6 割ぶん）。ねこの歩く速さは大きさに比例（どのレベルでも体の何倍ぶん進むかが同じ）。段階 t の合計は、その段階で行ける場所（`AREAS`：部屋は段階 1〜、モールは 3〜、街は 5〜、宇宙は 10〜）の物だけで数えるので、部屋の中だけで Lv.3、モールの中だけで Lv.5 まで上がれる
- 棚やテーブルの上の物は、台を壊すと落ちる
- Lv.10 になると「地球を飛び出す」演出（上へ飛び、空が黒くなり、白く光る）のあと宇宙ステージへ。宇宙では破片が落ちずに漂う。宇宙の物は `place(..., { scale })` で大きめに置き、段階 11・12 の物（惑星・太陽）はそのレベルになると「ポンッ」と現れる（それまでは見えず、当たり判定もない）。着いた所のまわり半径約 3.5km は空けてある`?debug` で `game.setLevel(10)` とすると演出なしで宇宙へ行ける
- 物の形は `src/core/shapes.js` のヘルパー（角の丸い箱 `rbox`・回転体 `lathe`・多面体 `ico`・ラベル用の筒 `tube`、絵柄の `texMat` / `screenMat`）で作る。置く時に素材ごとに 1 つのメッシュへ合体して描画を軽くしている（`mergeGroup`）
- 太陽の影はねこのまわりだけに落とす（大きくなると範囲も広がる）。ねこにくらべて小さい物は影も描画も省く
- 画質（`src/config.js` の `QUALITY`）：描く回数の上限（標準・高は 1 秒 60 回、低は 30 回、タイトル画面は 30 回、図鑑を開いている間は止める）、解像度、MSAA、光のにじみ（半分の解像度で計算）、ミニチュア風ぼかし。選んだ画質は localStorage の `nekopunch.quality` に覚える

## 音

- 効果音は `assets/audio/se/<名前>_<番号>.ogg`（同じ音が 3 パターン）。壊した物の段階で割れる音を変え、大きい物ほど低く再生して合成の「ドーン」を重ねる。素材がない音は WebAudio で合成（`src/core/audio.js`）
- BGM は場所で切り替わる：ねこ部屋・モール（Lv.1〜4）→ 街（Lv.5〜7）→ 超高層ビル街・山と海（Lv.8〜9）→ 宇宙（Lv.10〜11）→ 最後（Lv.12）
- 足音は床（部屋の木・モール・外）で変わり、大きくなるとズシンと画面が揺れる
- 素材はすべて CC0。出どころは `assets/audio/CREDITS.md`

## ファイル

```
src/config.js     キー割り当て・成長バランス・段階の定義
src/props.js      モールの物のカタログ（形・段階・金額）。ここに足せば新しい物を置ける
src/propsRoom.js  ねこ部屋の家具・小物と、モールに足した物
src/propsTown.js  街の建物（窓テクスチャつきの家・マンション・ビル・観覧車・ねこタワーなど）
src/mall.js       ねこ部屋とモールの配置（place / onTop / wallLine）、カメラをさえぎる物を透けさせる処理
src/town.js       街の区画の生成（モールから離れるほど大きな建物）と、その外の山・海
src/propsSpace.js 宇宙の物（人工衛星・ロケット・UFO・小惑星・惑星・太陽）
src/space.js      宇宙ステージの配置（地球から遠い x = 500000 に、天の川の床を敷いて並べる）と星空
src/hero.js       ねこ（大きさ・移動・パンチの見た目）
src/combat.js     パンチの当たり判定・破壊・破片・つぶし・落下
src/shoppers.js   お客さんのねこ（壊せない。近くで暴れると逃げる）
src/hud.js        画面の表示
src/game.js       全体（レベル・カメラ・崩壊エンディング）
src/gallery.js    物の見本帳（?gallery、開発用）
src/zukan.js      ねこパンチ図鑑（G で開く。壊した物の記録は localStorage の nekopunch.zukan.v1）
src/core/         描画の土台（エンジン・ポストプロセス・形のヘルパー・音・入力など）
```
